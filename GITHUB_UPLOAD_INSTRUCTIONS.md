# Uploading this package to GitHub

1. Create a new repository, for example `interpretive-probes-r2-2`.
2. Unzip the package locally.
3. Upload the **contents** of the `interpretive-probes-r2-2` folder, keeping the directory structure intact.
4. Before making the repository public, choose a license and add the final paper citation/DOI when available.
5. Do not add API keys, `.env` files, Colab secrets, or provider billing information.

The package is already sanitized to remove provider response IDs and contains no API keys.
