# Framework and scenario mapping

The paper treats interpretive competence as a property of the human participant in an AI-mediated knowledge transaction, not as a property of the model. The four sites arise by crossing the object of scrutiny (the user's contribution or the generated representation) with scale (local/bounded or relational/cumulative).

| Interpretive site | Object of scrutiny | Scale | Illustrative run |
|---|---|---|---|
| Framing awareness | User contribution | Local/bounded | S1: hypercalcemia formulations |
| Uncertainty detection | Generated representation | Local/bounded | S2: corticosteroids in community-acquired pneumonia |
| Evidential coherence judgment | Generated representation | Relational/cumulative | S3: heterogeneous Procedure K studies |
| Interactional reflexivity | User contribution / interaction trajectory | Relational/cumulative | S4: neutral vs steered multi-turn synthesis |

S5 (engineering standards) and S6 (science communication) are cross-domain illustrations of related transaction-level vulnerabilities.

The model runs are illustrative. They were not designed to validate the four competencies, estimate failure prevalence, compare model quality, or produce a benchmark.
